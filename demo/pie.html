CssCharts.render(el, {
  type: 'pie',
  data: [
    { name: 'Organic', value: 42 },
    { name: 'Paid', value: 28 },
    { name: 'Referral', value: 18 },
    { name: 'Social', value: 12 },
  ],
  // valueKey: 'value',  // default
  // donut: true,
  // innerRadius: 0.55,  // 0–1, fraction of outer radius
  ariaLabel: 'Traffic by channel',
  caption: 'Traffic by channel',
});

/* Geometry lives on a custom property → border-shape (not clip-path) */
.cc-pie-slice {
  --cc-slice-shape: shape(
    from 50% 50%,
    line to 50% 0.5%,
    arc to 99.5% 50% of 49.5% small cw,
    close
  );
  border-shape: var(--cc-slice-shape);
  border: 2px solid color-mix(in oklch, var(--cc-series) 35%, white);
  box-shadow: 0 2px 10px …;
}

Why not corner-shape? It only changes how border-radius curves look (squircle, bevel, scoop…). Pie wedges need full path geometry → border-shape + shape(). Angles start at 12 o’clock, clockwise; large sweeps use the large arc flag.

Theme borders with --cc-pie-slice-border-width and --cc-pie-slice-border-color. Requires a browser that implements border-shape (Chromium experimental / Interop track).
