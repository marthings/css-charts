JSON → DOM

CssCharts.render(el, {
  type: 'line',
  data: [ /* rows */ ],
  series: [
    { key: 'uv', label: 'UV' },
    { key: 'pv', label: 'PV', area: true, curve: 'smooth' },
  ],
  curve: 'straight', // chart default: 'straight' | 'smooth' (or true/false)
  // area: false,
  // dots: true,
  // lineWidth: 0.9,
  max: 5000,
});

Straight: line to between points.
Smooth: cubic curve to … with cp1 / cp2 (Catmull–Rom style).
Per-series curve overrides the chart setting.
