Open source · pure HTML/CSS

Charts from JSON, painted by CSS

CssCharts.render() turns data into DOM. Bar, line, combo, and pie — no SVG, no canvas. Theme with custom properties.

Bar Simple, grouped, stacked, horizontal Line Straight or smooth, area, multi-series Combo Bar + line, optional right Y-axis Pie Pie and donut via shape() arcs Theme CSS variables, transparent by default

Preview

Grouped bar

Model

JSON → DOM → CSS

  • Bar / Line / Combo / Pie type on render(); series and layout as options
  • Tooltips interestfor + popover="hint"
  • Accessibility Hidden data table, keyboard marks, focus rings

Install

Two files

<link rel="stylesheet" href="src/css-charts.css">
<script src="src/css-charts.js"></script>
<div id="chart"></div>
<script>
CssCharts.render(document.getElementById('chart'), {
  type: 'bar',
  data: [
    { name: 'A', uv: 4000, pv: 2400 },
    { name: 'B', uv: 3000, pv: 1398 },
  ],
  series: [
    { key: 'uv', label: 'UV' },
    { key: 'pv', label: 'PV' },
  ],
  layout: 'group',
});
</script>
