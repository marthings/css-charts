How it works

Put tokens on any ancestor. The chart and shell inherit them. Site chrome (this page’s header) can keep the default palette while cards use their own. 

.theme-ocean {
  /* series + type */
  --cc-s1: #38bdf8;
  --cc-s2: #22d3ee;
  --cc-text: #e0f2fe;
  --cc-muted: #7dd3fc;
  --cc-accent: #38bdf8;

  /* semantic chrome (default is transparent — opt in here) */
  --cc-shell-bg: rgb(56 189 248 / 0.06);
  --cc-shell-border: rgb(125 211 252 / 0.18);
  --cc-plot-bg: rgb(56 189 248 / 0.08);
  --cc-plot-border: rgb(125 211 252 / 0.28);
  --cc-grid-color: rgb(125 211 252 / 0.2);
  --cc-tip-bg: #0c1929;
  --cc-mark-bg: #0c1929;
}

CssCharts.render(el, { type: 'bar', data, series: [/*…*/] });
